# ServeRest — testes automatizados com Playwright + TypeScript

Projeto de portfólio de QA: plano de testes, casos de teste e automação de testes de API e de ponta a ponta (E2E) para o [ServeRest](https://serverest.dev), uma API REST e uma loja virtual criadas para a prática de testes.

> 🚧 Em construção. O progresso está registrado nos commits.

## O que este projeto vai ter

- [ ] Plano de testes
- [ ] Casos de teste em Gherkin
- [ ] Testes de API: login e usuários
- [ ] Testes de API: produtos e carrinhos
- [ ] Integração contínua no GitHub Actions, com relatório publicado
- [ ] Testes de ponta a ponta no front-end

## Tecnologias

- [Playwright](https://playwright.dev) com TypeScript
- Node.js
- GitHub Actions
